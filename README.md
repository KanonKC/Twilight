## Preresquisite
- [FFmpeg](https://www.ffmpeg.org/)
- Python
- Node.js

## Installation
1. Install `node_module` by command below.
```
npm install
```
2. Install Python packages. Starting by create a virtual environment
```
python -m venv env
```
Then, we access to it.
- For Window
```
source ./env/Script/activate
```
- For Linux / MacOS
```
source ./env/bin/activate
```
You should see `(env)` on the left-handed side in the command-line. Now we can install Python package by
```
pip install -r requirements.txt
```
